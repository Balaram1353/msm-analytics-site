Case Studies

Real problems we've helped clients solve

A sample of recent engagements — from analytics tooling to production-scale predictive models.

MSIG

Interactive Competitive Analysis Dashboard

Built an interactive Power BI dashboard for exploring competitors, clusters, and product performance — dynamic slicers and auto-surfaced comparisons replaced hours of manual filtering with a self-serve tool.

QuantivRisk

Probabilistic Accident-Cause Analysis

Built a Bayesian model that scores each candidate cause — like excessive speed — behind a vehicle accident from pre-accident telemetry, replacing a single black-box verdict with an explainable probability breakdown.

Built four segmented premium-prediction models — three state-specific plus one general — achieving 19–30% MAPE, with hands-on AWS SageMaker expertise to train and deploy models like this in production.
